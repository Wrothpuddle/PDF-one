# Third-party software notices

The Windows build includes PySide6/Qt 6 and Qt PDF (which uses PDFium), pypdf, plus PyInstaller. Exact license texts and third-party attributions must be collected from the installed package versions and included with any redistributed build.

Qt modules have per-module LGPLv3/GPLv3/commercial terms. Qt PDF's PDFium code is BSD-style, and PDFium's dependency tree contains additional notices. pypdf is BSD-3-Clause licensed. Its optional cryptography backend is dual-licensed Apache-2.0 OR BSD-3-Clause. PyInstaller is GPL with a bootloader exception. See README.md for the distribution caveat. This starter does not yet ship a version-specific notice bundle; commercial distribution is blocked until that bundle and LGPL compliance are reviewed.
